## 2. Phase 0 문제 해결 결과

| 문제 | 원인 | 조치 | 결과 |
|---|---|---|---|
| 표의 한 단어 셀 미번역 | BabelDOC이 5글자 미만 텍스트를 건너뜀 | `--min-text-length 2`, 표 번역 켬, 프롬프트에 짧은 셀 번역 명시 | **해결.** Male→남성, High→높음, None→없음 |
| 인라인 수식 깨짐 (`$`, `%`) | 원본 PDF의 Cambria Math 문자 매핑이 깨져 있고, BabelDOC이 이 폰트를 수식에서 하드코딩으로 제외 | 실행기에서 판정 함수를 덮어써 Cambria Math를 수식으로 처리 | **해결.** u, i, 𝓛, λ 원래 기호로 표시. `--formula-hint`는 효과 없음 |
| 실행마다 용어가 다름 | 매번 용어를 새로 추출 | 논문별 용어집 저장 후 재사용 | **해결.** 두 실행 모두 Actor→행위자 22회, "배우" 0회 |
| 표 행 겹침 | BabelDOC 조판 한계 | 미해결 | dual 출력으로 대조. Phase 3 후보 |

## 3. 새로 발견해 고친 문제

- 프롬프트의 "용어 첫 등장 시 영문 병기" 규칙 때문에 문단이 길어져 BabelDOC이 글자를 아주 작게 줄였다. 규칙을 빼고 "원문만큼 간결하게"로 바꾸자 정상 크기로 돌아왔다.

- 세 번째 논문(CHI '26, 17쪽)에서 참고문헌이 크게 망가졌다. 영어 그대로인데 연도, 권호, 쪽수 조각이 엉뚱한 위치로 흩어졌다. BabelDOC에는 참고문헌 제외 기능이 없다. 그래서 번역 후 영문 원본에서 "References" 제목을 찾아, 그 아래 영역과 이어지는 참고문헌 페이지를 원본으로 되돌리는 후처리를 넣었다.
  - 2단 레이아웃을 단별로 처리한다. 같은 페이지의 결론과 감사의 글은 한글로 남는다.
  - 부록 제목이 나오면 멈춘다. SDV 논문은 참고문헌 뒤 부록이 한글로 유지된다.
  - 페이지 위쪽의 전체 폭 표나 그림 아래부터만 오른쪽 단을 복원한다. Cold-start 논문의 표가 반쪽만 영어로 바뀌던 문제를 막는다.
  - 세 논문 모두 확인했다. 복원 페이지는 SDV 5쪽, Cold-start 4쪽, CHI 논문 14~17쪽이다.
  - 단일본(mono)에만 적용한다. 병기본(dual)에는 원문 페이지가 이미 있다.

## 4. 측정

| 실행 | 시간 | 호출 | 입력 토큰 | 출력 토큰 |
|---|---|---|---|---|
| SDV 8쪽, 첫 번역 | 177초 | 99 | 236K | 39K |
| SDV 8쪽, 재번역 (용어집 재사용) | 122초 | 67 | 178K | 23K |
| Cold-start 4쪽, 첫 번역 | 99초 | 44 | 114K | 23K |
| Cold-start 2쪽만, Sonnet | 38초 | 6 | 16K | 3K |
| Cold-start 2쪽만, Opus | 35초 | 5 | 15K | 4K |
| Unsent messages 17쪽, 첫 번역 | 364초 | 170 | 478K | 121K |

- 재번역은 시간 31%, 입력 토큰 25% 감소. 용어 추출 단계를 건너뛴 효과다.
- 프록시 응답 캐시는 재번역에서 적중하지 않았다. 용어집 내용이 프롬프트에 들어가 프롬프트가 달라지기 때문이다. 캐시는 실패 후 재시도용으로만 의미가 있다.
- Opus와 Sonnet의 번역 품질은 거의 같았다. 기본 모델은 Sonnet으로 유지한다.
- 모든 실행에서 오류와 한도 초과는 0건이었다.
- 17쪽 논문 기준 페이지당 약 21초, 약 35K 토큰이다.

## 5. 남은 과제 (Phase 2·3)

- 참고문헌도 여전히 번역 요청에는 포함된다. 결과만 원본으로 되돌리므로 그만큼 토큰이 낭비된다

- 표 행 겹침 보정
- 자동 용어집에 학회명 같은 고유명사가 번역되어 들어가는 경우 필터링
- 그림 내부 텍스트는 번역하지 않음 (BabelDOC 설계)
- 웹 UI와 진행률 표시 (BabelDOC 진행률은 파일로 리다이렉트하면 최종 상태만 남으므로, 프록시 호출 로그 기반 진행률이 필요)
- API 백엔드는 코드만 작성했고 실제 호출은 검증하지 않았다 (API 키 없음)
